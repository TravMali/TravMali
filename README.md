### [Metasploitable 2 Penetration Test Report](https://github.com/TravMali/Penetration-Test-Report---Metasploitable-2/blob/main/Metasploitable%202%20Penetration%20Test.pdf)
* **Key Tech:** Metasploit, Kali Linux, Docker, Nmap
* **Highlights:**
   * **Vulnerability Exploitation:** Exploited the VSFTPD 2.3.4 backdoor (CVE-2011-2523), Apache JServ Ghostcat file-read (CVE-2020-1938), and UnrealIRCd trojan backdoor (CVE-2010-2075) using Metasploit modules, gaining remote shell access and reading privileged files without credentials.
   * **Reconnaissance & Enumeration:** Performed TCP port and service scans to fingerprint outdated services and map attack surface prior to exploitation.
   * **Proof of Concept:** Documented full exploit chains with screenshots and command output, demonstrating attacker capabilities including unauthorized shell access, persistence potential, and remote code execution risk.
   * **Remediation & Reporting:** Authored a formal penetration test report with severity ratings and remediation guidance covering version patching, SFTP migration, AJP connector restriction to localhost, and firewall rules limiting service ports to authorized hosts.
   * **Lab Environment:** Built an isolated attack lab with Kali Linux and a Docker-contained Metasploitable 2 victim machine, simulating a legacy unpatched enterprise server.
